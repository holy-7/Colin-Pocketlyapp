# Colin记账

> 个人记账 APP — 用 Loop Engineering 方法论驱动开发

- **状态**：需求设计阶段
- **开始日期**：2026-07-20
- **预计 MVP-1 完成**：TBD（待技术栈选定后估算）
- **目标**：打造数据自控、极简无广告、AI 驱动的个人财务管家
- **方法论**：Loop Engineering（[[06-Wiki/Loop-Engineering]]）

## 关键结果

1. **KR1：MVP-1 上线桌面端** — Electron 桌面应用，手动记账 + 基础报表，跑通"记一笔 → 看汇总"主流程
2. **KR2：双端可用** — 移动端 APP 上线，数据云同步，随时随地能记账
3. **KR3：AI 助手 V1.0** — 对话式分析 + 智能推荐，形成差异化竞争力
4. **KR4：生产级 Loop** — 自动化 CI/CD + 代码审查 + 测试覆盖
